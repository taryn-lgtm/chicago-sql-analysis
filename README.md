# Chicago Data Analysis Using SQL

## Project Overview

An exploratory data analysis project investigating crime, socioeconomic conditions and public school safety across Chicago.

Completed as part of the IBM Databases and SQL for Data Science with Python course.

## Technologies

- Python
- SQL (SQLite)
- pandas
- Jupyter Notebook
- ipython-sql

## Datasets

Three publicly available Chicago datasets:

1. Chicago Census Data
2. Chicago Public Schools
3. Chicago Crime Data

## Analysis

The project uses SQL queries to investigate:

- Crime frequencies and geographical distribution
- Crimes involving minors and incidents at schools
- Average school safety scores
- Community areas with high poverty rates
- Relationships between community areas and socioeconomic hardship

## SQL Skills Demonstrated

- `SELECT`, `WHERE`, `ORDER BY` and `LIMIT`
- Aggregate functions: `COUNT()`, `AVG()` and `MAX()`
- `GROUP BY` and `DISTINCT`
- Pattern matching using `LIKE`
- Subqueries and cross-table lookups

## Selected Findings

- 533 crime records analysed.
- Community area 25 had the highest number of recorded crimes in the sample.
- Riverdale had the highest hardship index.
- Austin was identified as the community area corresponding to the highest crime count.

These findings describe the provided coursework dataset, not necessarily current or citywide crime trends.

## Project Files

- `chicago-sql-analysis.ipynb` — Complete SQL analysis, queries and results.

## How to Run

1. Install Python, pandas, ipython-sql and prettytable.
2. Open the notebook in Jupyter.
3. Run the setup cells to load the datasets into SQLite.
4. Execute the SQL queries to reproduce the analysis.
